# 小論文ワークシートの作り方

東洋大学 食環境科学部版（`shoronbun/examples/toyo_food_datascience.json`）と同じ形式の教材を、別の大学・テーマで作る。
デザインは `shoronbun/render.py` が自動で組むので、Claude がやるのは **内容 JSON を書くこと** だけ。

## 手順

1. **依頼を整理する**: 大学・学部・学科・入試方式・テーマ（1つ目がお手本、既定は計4テーマ）。足りない情報は、調べて分かる範囲で埋め、分からなければ想定値で進める（質問で止めない）。
2. **調べる**: WebSearch で、大学公式の学生募集要項・入試ガイド・過去問公開ページ・アドミッションポリシーを優先して、試験時間・字数・出題形式・過去のテーマを確認する。参照 URL を控える。
3. **JSON を書く**: `shoronbun/schema.py` の `WORKSHEET_SCHEMA` に従い、`shoronbun/prompts.py` の `COMPOSE_SYSTEM`（方針・事実の扱い・字数の目安）をそのまま守って書く。手本は東洋大学版の JSON。保存先は `shoronbun/out/<大学>_<学部>/content.json`。
   - 過去問と確認できないものは source を「オリジナル予想問題（〇〇学部の出題傾向に準拠）」にする。
   - 試験条件が確認できなければ exam.note に「※ 試験時間・字数は想定。必ず最新の学生募集要項で確認すること。」
   - 統計は出典が確かなものだけ（material.note に出典）。
4. **検証する**:
   ```bash
   cd shoronbun
   python3 -c "import json,sys; from schema import validate, char_report; d=json.load(open(sys.argv[1])); validate(d); print(char_report(d))" out/<…>/content.json
   ```
   模範解答の字数が規定の 90〜100% に入っていない（`ok: False`）なら、本文を直して再検証する。字数は空白を除いた文字数。
5. **スライドにする**: `python3 render.py out/<…>/content.json out/<…>/<大学>_<学部>_小論文ワークシート.pptx`
6. **目視で確認する**: pptx スキルの手順で PDF→画像にして全スライドを見る（文字のはみ出し・重なり・空きすぎ）。崩れていれば、該当テキストを短くして 4〜5 をやり直す。
7. **報告する**: 生成ファイル、各テーマの字数、確認できた事実と想定で置いた値（要項で確認すべき点）、参照 URL。

## スライド構成（render.py が自動で作る）

表紙 → 試験の全体像 → 時間配分 → 3つの問い → 答案の基本フォーム →
テーマ1（お手本: 読む / Q1 / Q2 / Q3 / 模範解答）→ テーマ2以降（演習: 読む / ワークシート① / ② / 模範メモ / 模範解答）→ 見直し

- 時間配分（読む・構成・書く・見直す）は試験時間から自動計算（60分 → 5/10/35/10）。`exam.time_split` で上書きできる。
- 「9割＝◯字」、各解答の字数内訳、テーマ数に応じた文言は自動で入る。
- 長い模範解答は文字を小さくし、それでも入らなければ2枚に分ける。
