AI自動添削システム　はじめにお読みください（設置する人向け）
==================================================

このフォルダ一式を、添削を動かすデスクトップ PC で次の手順のとおり設置してください。

■ 1. 必要なソフトを入れる（PC に 1 回だけ）
  (1) Claude Code
      https://claude.com/claude-code の手順でインストールし、
      インストール後に一度「claude」を起動してログインしておく
  (2) Git for Windows
      https://git-scm.com/download/win
  (3) Python
      https://www.python.org/downloads/
      ※ インストール画面の「Add python.exe to PATH」に必ずチェック

■ 2. フォルダを置く
  この「AI自動添削システム」フォルダを丸ごと
    OneDrive ＞ 00AIGod
  の中に置く。
  → OneDrive\00AIGod\AI自動添削システム になれば OK

■ 3. セットアップ
  「AI自動添削システム」の中の「セットアップ.bat」をダブルクリック。
  ・すべて OK と出れば完了（毎日 13:00 と 21:00 に自動で添削するよう登録されます）
  ・NG が出たら、表示された内容を直してもう一度ダブルクリック
  ・「Windows によって PC が保護されました」と出たら
    「詳細情報」→「実行」を押す

■ 4. 動作確認
  (1) 提出のしかた.txt のとおりに、提出物を 1 件「添削前」に入れる
  (2) 10 分待つ（同期待ちの時間）
  (3) 「添削実行.bat」をダブルクリック
  (4) 「添削後」に「…_添削完了.docx」と「納品一覧.txt」ができれば成功
      うまくいかないときは「ログ」フォルダの最新ファイルを確認

■ 5. 先生に共有する
  OneDrive で「添削前」「添削後」を先生と共有し、「提出のしかた.txt」を渡す。
  ※ CLAUDE.md や tools フォルダを書き換えられないよう、
     フォルダ全体ではなく「添削前」（編集可）と「添削後」（閲覧のみ）だけの共有がおすすめ

■ 中身
  はじめにお読みください.txt … このファイル
  提出のしかた.txt          … 先生向けの提出ルール
  セットアップ.bat          … 初回だけ実行
  添削実行.bat              … 今すぐ手動で添削するとき
  CLAUDE.md                 … 添削のルール（Claude Code が自動で読む。方針を変えるときはここを編集）
  tools\                    … 自動実行・Word 作成などのプログラム（触らない）
  添削前\ 添削後\            … 提出と納品の場所

■ デスクトップへの保存
  添削結果の Word は「添削後」に加えて、デスクトップの「AI自動添削_納品物」フォルダにも自動で保存されます。
