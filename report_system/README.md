# 学習報告書 自動送信システム

授業後に講師がスマホで質問に答える → 教室長が確認して✓ → 保護者の **LINE** か **メール**（または両方）に自動で届く。
Google フォーム＋スプレッドシート＋Apps Script だけで動きます（サーバー不要・Google 側は無料）。

```
講師（スマホ）            教室長（PC・スマホ）                保護者
Googleフォームで回答 ──▶ 「報告書」シートに「確認待ち」で1行 
                         必要なら本文を直して「承認」に✓ ──▶ LINE公式アカウント／メール
                         （送れなければ「送信エラー」と理由が出る）
```

- 報告書の型（質問と、届く文面の見本）… [`学習報告書_質問票.md`](学習報告書_質問票.md)
- プログラム … `貼り付け用_コード.gs`（Apps Script に丸ごと貼る1ファイル版）。元のファイルは `apps_script/`。直したら `node build_bundle.js` で作り直す
- 引き継ぎ … [`引き継ぎ.md`](引き継ぎ.md)（本体PCで続きをするとき）
- 動作確認 … `node test/run_tests.js`（Google のモックで、フォームの分岐・回答→承認→送信・LINE連携・再送・二重送信防止の30項目）

## 送り先：LINE公式アカウント（メールも併用可）

保護者には **LINE公式アカウント（Messaging API）** から届けます。LINE を使っていない家庭だけメールにする、父母でLINEとメールに分ける、もできます。生徒ごとに「生徒マスタ」の **送信方法** 列で `LINE`／`LINE＋メール`／`メール`／`送らない` を選びます。

**LINE の通数と費用の目安**（2026年11月時点。最新は [LINEヤフー for Business](https://www.lycbiz.com/jp/column/line-official-account/technique/20200204/) で確認）

- 無料のコミュニケーションプランは**月200通まで**。超える場合は有料プラン（ライトプラン 月5,000円で5,000通 など）。
- 報告書1通 × 受け取る保護者の人数 ＝ 通数。父母2人で受け取ると2通。
- **PLATZ（生徒50人）の目安**：週1回なら月約215通、週2回なら月約430通 → **無料枠（200通）を超えるので、ライトプラン（月5,000円・5,000通）** が目安。父母2人で受け取る家庭が多くても 5,000通には届きません。
- 無料枠を超えると、その月は LINE に送れなくなります（「送信エラー」になり、理由が出ます）。メールも登録しておけば、送信方法を「LINE＋メール」にして予備にできます。

> LINE Notify は 2025年3月に終了したため使えません。

## 1. Google 側の準備（15分）

**→ [`手順1_Googleの準備.md`](手順1_Googleの準備.md)** に、画面の順番どおりに書いてあります。

要点：スプレッドシートを作る → **拡張機能 → Apps Script** の「コード.gs」に [`貼り付け用_コード.gs`](貼り付け用_コード.gs) を丸ごと貼り付けて保存 → スプレッドシートを再読み込み → **学習報告書 → ① 初期設定** → 先生ご自身のメールで1件試す。

## 2. LINE の準備（30分）

1. [LINE Official Account Manager](https://manager.line.biz/) で PLATZ の公式アカウントを開く（すでにあるアカウントをそのまま使えます。今の友だちもそのまま）。
2. 公式アカウントの **設定 → Messaging API → Messaging APIを利用する**（プロバイダーは「個人指導塾PLATZ」で作成。すでに有効なら飛ばす）。
3. [LINE Developers](https://developers.line.biz/console/) で同じチャネルを開き、**Messaging API設定 → チャネルアクセストークン（長期）→ 発行**。
4. スプレッドシートの **学習報告書 → LINEの設定** にトークンを貼る（シートには保存されず、スクリプトの中にだけ保存されます）。「接続できました」と出ればOK。
5. Apps Script の **デプロイ → 新しいデプロイ → 種類：ウェブアプリ**、「次のユーザーとして実行：自分」「アクセスできるユーザー：全員」でデプロイし、ウェブアプリの URL をコピー。
6. LINE Developers の **Messaging API設定 → Webhook URL** に貼り、**Webhookの利用** をオン。
   （「検証」ボタンでエラーと出ることがありますが、Apps Script の仕様によるもので、下の手順で連携できれば問題ありません）
7. LINE Official Account Manager の **設定 → 応答設定**：
   - **Webhook**：オン
   - **応答メッセージ**：オフ（今の自動応答は使わない）
   - **あいさつメッセージ**：オフ（友だち追加のときは、このシステムが「個人指導塾PLATZです。友だち追加ありがとうございます。お手元の連携コードを…」と案内します。文面は設定シートの「LINE連携の案内文」で変えられます）
   - **チャット**：オン（保護者からの普通のメッセージには、今までどおり手で返信できます）
   - あとであいさつメッセージを使いたくなったら、設定シートの「友だち追加のときに連携の案内を送る」を「いいえ」にしてください（二重に届かないように）。

> コードを直したら、**デプロイを管理 → 編集 → バージョン：新バージョン** で更新します（URL は変わりません）。

### 保護者の LINE をつなぐ

1. 生徒マスタでその生徒の行を選び、**学習報告書 → 選択した生徒の連携コードを発行**（例：`K7M2QX`）。
2. 保護者に「公式アカウントを友だち追加して、トークに `K7M2QX` と送ってください」と伝える（入塾書類や面談で）。
3. 保護者が送ると「〇〇さんの学習報告書が、このLINEに届くようになりました」と自動で返信され、生徒マスタに LINEユーザーID と連携日時が入ります。送信方法が「メール」だった生徒は「LINE＋メール」になります。

- コードは1回使うと消えます。父母2人で受け取るときは、もう一度発行して2人目に送ってもらいます（IDが2行になり、両方に届きます）。
- 全角・小文字・空白が混じっていても読み取ります。コード以外の普通のメッセージには反応しません。

## 3. 毎日の使い方

**講師**：授業が終わったらフォームに答えて送信。区分（小学生／中学生／高校生）を選ぶと、その学年の科目が出ます。2科目教えた日は「2科目目」で科目を選ぶと、2科目目のページが出ます。

**教室長**：「報告書」シートを開く。
1. 「確認待ち」の行の **要確認**（区分と学年が合わない、など）と **送信本文** を読む（直したいところはセルを直接書き換えてOK。直した文面がそのまま送られます）。
2. **承認** に✓ → すぐ送られ、ステータスが「送信済み」になる。
3. 「送信エラー」になったら **エラー** 列を見て直し（例：LINE未連携、メールアドレスが空）、**承認済みをまとめて送る** で再送。すでに届いた宛先には二度送りません。

その他のメニュー：
- **選択した行を自分にテスト送信** … 保護者に送る前に、自分のメールで見た目を確認。
- **選択した行の本文を作り直す** … 回答のセル（理解度など）を直したあと、本文を作り直す。
- 設定シートの「承認したらすぐ送る」を「いいえ」にすると、✓を付けただけでは送らず、**承認済みをまとめて送る** でまとめて送ります（例：夜にまとめて送る）。

## 安全のための仕組み

- 教室長が✓を付けるまで、保護者には何も送られない（フォームのURLが外に漏れても、勝手に送られない）。
- 「教室長への申し送り」は保護者向けの本文に入らない。
- 二重送信の防止：送れた宛先は「送信先」列に「済」と記録し、再送では飛ばす。LINE には `X-Line-Retry-Key` も付ける。
- LINE連携は、コードを知っている人だけ・1回限り・公式アカウントの友だちであることを LINE に確認してから。
  （Apps Script は LINE の署名ヘッダーを読めないため、署名検証の代わりにこの3つで守っています）
- LINE のトークンはシートに置かない（スクリプトプロパティに保存）。
- すべての送信・連携は「送信ログ」シートに残る。

## 動作確認について

`test/run_tests.js` は Google の API をまねたモックの上で動かしたテストです。**実際の Google・LINE 上ではまだ動かしていません。** 初回は、自分を保護者役にして（自分のメールアドレス・自分のLINEで連携）1件通しで試してください。
