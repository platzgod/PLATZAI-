# 引き継ぎ：学習報告書 自動送信システム（個人指導塾PLATZ）

作成：2026年11月2日　／　リポジトリ：`platzgod/PLATZAI-`　ブランチ：`claude/lucid-mccarthy-uwg1n7`　フォルダ：`report_system/`

本体PCで続きをするための引き継ぎです。**人が読んでも、本体PCの Claude Code に読ませても**進められるように書いています。
Claude Code に任せるときは、このファイルを開いて「この引き継ぎの『次にやること』を進めて」と伝えてください。

---

## 1. 何を作ったか

授業後の学習報告書を、講師がスマホで答え → 教室長が確認して✓ → 保護者の LINE（とメール）に自動で届ける仕組み。
Google フォーム＋スプレッドシート＋Apps Script だけで動く（サーバー不要）。

```
講師（スマホ）            教室長                                  保護者
Googleフォームで回答 ──▶ 「報告書」シートに「確認待ち」で1行
                         本文を確認（直せる）→「承認」に✓ ──▶ LINE公式アカウント／メール
```

## 2. 決まっていること（塾長と確認済み）

| 項目 | 決定 |
|---|---|
| 塾名 | 個人指導塾PLATZ（教室名・電話番号は報告書に載せない） |
| 送り先 | **LINE公式アカウント**（既存のアカウントを使う）。メールは家庭ごとに予備で使える |
| 入力 | 講師がスマホの Google フォームで回答 |
| 送信 | **教室長が確認して✓を付けてから送る**（✓ですぐ送信） |
| 報告項目 | 学習内容・理解度／授業態度・小テスト／宿題／講師コメント・連絡（＋教室長への申し送り＝保護者に送らない） |
| 区分 | 小学生・中学生・高校生で科目の選択肢を分ける |
| 科目数 | 1回の授業で2科目のことがある → 2科目目は任意で追加 |
| 文面 | 保護者向け・丁寧（見本：`学習報告書_質問票.md`） |
| 生徒数 | 約50人 → LINE は無料枠（月200通）を超えるので **ライトプラン（月5,000円・5,000通）** が目安 |
| 生徒名簿 | 合格一貫カリキュラムの名簿とは別に、このシステムの「生徒マスタ」で管理 |
| LINEの応答設定 | 今の自動応答・あいさつメッセージは**使わなくてよい**（オフにする）。友だち追加時の案内はこのシステムが送る。チャットはオンのまま |

### 3-1. 2026年11月2日 追記（クラウド版 Claude Code で事前に直したこと）

Google・LINE へのログインはクラウドからはできないため、ステップ1以降の前に、実機で困りそうな点を先に直しました。

- **小テスト「8/10」が日付（8月10日）に化ける問題**を修正。報告書シートの回答の列は「書式なしテキスト」で書き込むようにした。「=」「+」で始まる文が数式エラーになる問題も同時に解消。
- **質問を増やしたあと列がずれる問題**を修正。報告書シートには見出しの名前で書き込み、新しい質問の列は右端に自動で足す。
- **同時に2件届いたとき**に✓欄が別の行に付く可能性があったので、書き込み中はロックするようにした。
- Webhook など、開いているスプレッドシートが取れない呼ばれ方に備えて、初期設定でスプレッドシートの ID を覚えておくようにした。
- `apps_script/.gitignore` で `.clasp.json` をコミットしないようにした。
- 手順の clasp コマンド（`clasp create --type sheets --title … --rootDir .` ／ `clasp push --force`）が最新の clasp 3.4.1 でもそのまま使えること、`clasp push` で送られるのが6つの `.gs` と `appsscript.json` だけであることを確認済み。
- テストは32項目（上の自動変換・列ずれのテストを追加。モックも本物のシートと同じく文字を自動変換するようにした）。

## 4. 次にやること

### ステップ1　Google に作る（どちらか一方）

**方法A：手で貼り付ける（約15分）** … `手順1_Googleの準備.md` のとおり。

**方法B：本体PCの Claude Code（またはターミナル）で clasp を使って作る（約5分＋クリック）**

前提：Node.js が入っていること。塾の Google アカウントで操作すること。

1. ブラウザで <https://script.google.com/home/usersettings> を開き、**Google Apps Script API を「オン」** にする（初回だけ）。
2. ターミナルで：

```bash
git clone https://github.com/platzgod/PLATZAI-.git
```

```bash
cd PLATZAI-
```

```bash
git checkout claude/lucid-mccarthy-uwg1n7
```

```bash
cd report_system && node test/run_tests.js
```

（最後に「32 件すべて成功」と出ればOK）

```bash
npm install -g @google/clasp
```

```bash
clasp login
```

（ブラウザが開くので、**塾の Google アカウント**で許可する）

```bash
cd apps_script && clasp create --type sheets --title "PLATZ 学習報告書" --rootDir .
```

（新しいスプレッドシート「PLATZ 学習報告書」と、それにつながったスクリプトができる。表示されるスプレッドシートのURLを控える。`.clasp.json` ができるが、コミットしない）

clasp create が手元の `appsscript.json` を上書きしたり、空の `Code.js` を作ったりすることがあるので、元に戻してから送る：

```bash
git checkout -- appsscript.json && rm -f Code.js Code.gs
```

```bash
clasp push --force
```

（`Config.gs` など6ファイルと `appsscript.json` が送られる）

3. ここから先は **人がブラウザで操作**（Google の許可は本人しかできないため）：
   - 控えたURLでスプレッドシートを開き、再読み込み → メニュー **学習報告書 → ① 初期設定**
   - 許可の画面：「続行」→ アカウント選択 →「詳細」→「PLATZ 学習報告書（安全ではないページ）に移動」→ すべて許可
   - もう一度 **① 初期設定** → 「初期設定が終わりました」とフォームURLが出ればOK
   - 確認のしかた（先生のメールで1件試す）は `手順1_Googleの準備.md` の **D** のとおり

> コードを直したとき：`apps_script/` を直す → `node ../build_bundle.js` と `node ../test/run_tests.js` → `clasp push --force`。
> フォームの質問を変えたときは、スプレッドシートで **学習報告書 → フォームを作り直す**。

### ステップ2　生徒・講師を登録する
- 「生徒マスタ」：生徒ID（S001…）、生徒名、学年（小5・中3・高2 のように「小／中／高」で始める）、保護者名、送信方法（LINE／LINE＋メール／メール／送らない）、メールアドレス（任意）、在籍（在籍／休塾／退塾）
- 「講師マスタ」：講師名、在籍

### ステップ3　LINE をつなぐ（約30分）… `README.md` の「2. LINE の準備」
1. LINE Official Account Manager で既存の公式アカウントの **Messaging API を有効化**
2. LINE Developers でチャネルアクセストークン（長期）を発行 → スプレッドシートの **学習報告書 → LINEの設定** に貼る

## 5. 気をつけること・未確認のこと

- **実機未確認**：Google フォームの分岐（区分 → 小／中／高のページ、2科目目の有無）、承認✓での即時送信（インストール型 onEdit トリガー）、LINE Webhook。最初の通しテストで確認する。
- LINE Webhook：Apps Script は受信ヘッダーを読めないので署名検証ができない。代わりに「コードを知っている人だけ・1回限り・プロフィールAPIで友だちか確認」で守っている。LINE Developers の「検証」ボタンはエラー表示になることがあるが、実際にコードを送って連携できればよい。
- Gmail（無料アカウント）のメール送信は1日100通まで。LINE が主なので通常は問題ない。
- LINE のトークンはシートではなくスクリプトプロパティ（`LINE_TOKEN`）に保存している。
- 料金・無料通数は2026年11月時点の情報。契約前に LINE 公式で確認する。
