# 学習報告書の型（講師が授業後に答える質問）

講師はスマホの Google フォームで質問に答えます（1科目なら約3分）。回答から**保護者向けの丁寧な文面が自動でできる**ので、講師が文章を整える必要はありません。
質問を変えるときは `apps_script/Config.gs` の `PAGES`／`QUESTIONS`／`SUBJECTS_BY_LEVEL` を直し、メニュー「フォームを作り直す」を実行します。

## フォームの進み方

```
① 授業の基本情報 ── 区分＝中学生 ─▶ ② 1科目目（中学生の科目）─┐
                 └─ 区分＝高校生 ─▶ ② 1科目目（高校生の科目）─┤
                                                               │「2科目目」＝なし（1科目だけ） ─▶ ③
                                                               └「2科目目」＝科目を選ぶ ─▶ ②-2 2科目目 ─▶ ③
③ 授業の様子・小テスト ─▶ ④ 宿題 ─▶ ⑤ 講師コメント・連絡 ─▶ 送信
```

1科目の授業では、2科目目のページは出てきません。

**科目の選択肢**

| 区分 | 科目 |
|---|---|
| 中学生 | 英語／数学／国語／理科／社会／英検対策／その他 |
| 高校生 | 英語／数学ⅠA／数学ⅡB／数学Ⅲ／数学C／現代文／古文・漢文／物理／化学／生物／地学／日本史／世界史／地理／公共・倫理・政経／情報／小論文／英検対策／その他 |

**授業中の様子の選択肢**：集中して取り組んでいた／積極的に質問していた／前回より理解が深まっていた／ていねいに解いていた／粘り強く考えていた／少し疲れている様子だった／集中が途切れることがあった

- 必須でない質問が空欄のときは、文面からその見出しごと消えます。
- 「教室長への申し送り」は報告書シートには残りますが、保護者には送りません。
- 報告書シートの「要確認」列に、区分と生徒の学年が合わない（例：高2の生徒に「中学生」）、1科目目と2科目目が同じ、などが出ます。送信は止めないので、教室長が見て判断します。

```

■ 数学ⅠA　理解度 ★★★★☆（4/5）
【学習内容】二次関数の最大・最小（定義域に文字を含む場合分け）
【教材】青チャート数I p.112〜118
◎ できたこと
軸と定義域の位置関係を図に描いて、3通りの場合分けを自分で整理できました。
△ これからの課題
場合分けの境目（等号を含むか）で迷うことがあります。次回、類題で確認します。

■ 英語　理解度 ★★★☆☆（3/5）
【学習内容】関係代名詞 what の用法
【教材】Next Stage p.88〜90
◎ できたこと
例文を自分で言い換えられるようになりました。
```

## 講師向け：書き方のコツ（研修用）

- **「できたこと」は具体的に**：「頑張っていました」ではなく「〇〇を自分で△△できた」。保護者が子どもを褒めるきっかけになります。
- **課題は「次にどうするか」とセットで**：「〜で迷う。次回、類題で確認します」。不安だけを伝えない。
- **ひとことは家庭でできることを1つ**：声かけの例などを書くと、家庭との連携になります。
- 生徒の個人的な事情や、他の生徒の話は書かない（気になることは「教室長への申し送り」に書く）。
