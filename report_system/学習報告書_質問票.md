# 学習報告書の型（講師が授業後に答える質問）

講師はスマホの Google フォームでこの18問に答えます（3分ほど）。回答から**保護者向けの文面が自動でできる**ので、講師が文章を整える必要はありません。
質問を変えるときは `apps_script/Config.gs` の `QUESTIONS` を直し、メニュー「フォームを作り直す」を実行します。

| # | 区切り | 質問 | 答え方 | 必須 | 保護者に送る |
|---|---|---|---|:-:|:-:|
| 1 | ① 授業の基本情報 | 講師名 | プルダウン（講師マスタ） | ● | ● |
| 2 | | 生徒名 | プルダウン（生徒マスタ「S001 山田 太郎」） | ● | ● |
| 3 | | 授業日 | 日付 | ● | ● |
| 4 | | 科目 | 英語／数学／国語／理科／社会／その他 | ● | ● |
| 5 | ② 学習内容と理解度 | 今日の学習内容（単元・テーマ） | 文章 | ● | ● |
| 6 | | 使った教材・ページ | 1行 | | ● |
| 7 | | 理解度 | 1〜5（まだ難しい ↔ よく理解できた） | ● | ●（★で表示） |
| 8 | | できたこと・よかったこと | 文章 | ● | ● |
| 9 | | これからの課題・つまずいたところ | 文章 | | ● |
| 10 | ③ 授業の様子・小テスト | 授業態度 | とても良い／良い／ふつう／もう少し | ● | ● |
| 11 | | 授業中の様子 | 複数選択（下の7つ） | | ● |
| 12 | | 小テストの結果 | 1行（例：8/10） | | ● |
| 13 | ④ 宿題 | 前回の宿題 | 全部できていた／一部できていた／できていなかった／前回は宿題なし | ● | ● |
| 14 | | 次回までの宿題 | 文章 | | ● |
| 15 | ⑤ 講師コメント・連絡 | 保護者へのひとこと | 文章 | ● | ● |
| 16 | | 次回の授業日 | 日付 | | ● |
| 17 | | 保護者への連絡事項 | 文章（振替・面談・持ち物など） | | ● |
| 18 | | 教室長への申し送り | 文章 | | **送らない** |

**授業中の様子の選択肢**：集中して取り組んでいた／積極的に質問していた／前回より理解が深まっていた／ていねいに解いていた／粘り強く考えていた／少し疲れている様子だった／集中が途切れることがあった

- 必須でない質問が空欄のときは、文面からその見出しごと消えます。
- 「教室長への申し送り」は報告書シートには残りますが、保護者には送りません。

## 保護者に届く文面（見本）

LINE・メールとも同じ文面です（メールの件名は「【学習報告書】山田 太郎さん 11月2日（月）」）。

```
【学習報告書】〇〇個別指導塾 駅前教室
━━━━━━━━━━━━
山田 太郎さん（高2）
授業日：2026年11月2日（月）
科目：数学　担当：佐藤 先生

■ 今日の学習内容
二次関数の最大・最小（定義域に文字を含む場合分け）
教材：青チャート数I p.112〜118

■ 理解度　★★★★☆（4/5）
◎ できたこと
軸と定義域の位置関係を図に描いて、3通りの場合分けを自分で整理できました。
△ これからの課題
場合分けの境目（等号を含むか）で迷うことがあります。次回、類題で確認します。

■ 授業の様子
授業態度：良い
・集中して取り組んでいた
・積極的に質問していた
小テスト：8／10点

■ 宿題
前回の宿題：全部できていた
次回までの宿題：
青チャート p.119〜121 の例題をノートに解く

■ 講師より
先週より解く手が止まらなくなってきました。ご家庭でも「図を描いてる？」と声をかけてみてください。

■ 次回の授業　11月9日（月）

■ ご連絡
11月16日（月）は教室休業日のため、振替をご相談させてください。
━━━━━━━━━━━━
ご不明な点は教室までお気軽にお問い合わせください。
0120-000-000
```

## 講師向け：書き方のコツ（研修用）

- **「できたこと」は具体的に**：「頑張っていました」ではなく「〇〇を自分で△△できた」。保護者が子どもを褒めるきっかけになります。
- **課題は「次にどうするか」とセットで**：「〜で迷う。次回、類題で確認します」。不安だけを伝えない。
- **ひとことは家庭でできることを1つ**：声かけの例などを書くと、家庭との連携になります。
- 生徒の個人的な事情や、他の生徒の話は書かない（気になることは「教室長への申し送り」に書く）。
