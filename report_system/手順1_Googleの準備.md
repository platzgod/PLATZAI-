# 手順1　Google の準備（約15分・パソコンで）

この手順が終わると、講師用のフォームで答えた報告書が、確認のあと**先生ご自身のメールに届く**ところまで動きます（LINE は手順3でつなぎます）。

用意するもの：塾で使っている Google アカウント（Gmail）、パソコン（Chrome がおすすめ）

---

## A. スプレッドシートを作る（1分）

1. [Google スプレッドシート](https://docs.google.com/spreadsheets/) を開き、塾の Google アカウントでログインしていることを右上で確認する。
2. 「空白のスプレッドシート」をクリック。
3. 左上の「無題のスプレッドシート」をクリックし、名前を **PLATZ 学習報告書** にする。

## B. プログラムを貼り付ける（3分）

1. スプレッドシートの上のメニューで **拡張機能 → Apps Script** をクリック（新しいタブが開く）。
2. 左上の「無題のプロジェクト」をクリックし、名前を **PLATZ 学習報告書** にする。
3. 真ん中に `function myFunction() { … }` と書かれた「コード.gs」が開いている。中をクリックし、**Ctrl＋A（Mac は ⌘＋A）→ Delete** で全部消す。
4. 下のどちらかで、プログラムをコピーする。
   - **GitHub から（おすすめ）**：[貼り付け用_コード.gs](https://github.com/platzgod/PLATZAI-/blob/claude/lucid-mccarthy-uwg1n7/report_system/%E8%B2%BC%E3%82%8A%E4%BB%98%E3%81%91%E7%94%A8_%E3%82%B3%E3%83%BC%E3%83%89.gs) を開き、右上の **コピーのボタン（Copy raw file）** をクリック。
   - ファイルから：`report_system/貼り付け用_コード.gs` をメモ帳などで開き、Ctrl＋A → Ctrl＋C。
5. Apps Script の「コード.gs」に **Ctrl＋V** で貼り付ける（約1,000行）。
6. **Ctrl＋S**（またはフロッピーの 💾 ボタン）で保存。赤い波線やエラーが出なければOK。

## C. 初期設定を実行する（5分）

1. スプレッドシートのタブに戻り、**ページを再読み込み（F5）** する。
2. 数秒待つと、上のメニューの「ヘルプ」の右に **学習報告書** が出る。
3. **学習報告書 → ① 初期設定（シート・フォームを作る）** をクリック。
4. 「承認が必要です」と出たら、次のとおり進める（初回だけ）。
   1. **続行** → 塾の Google アカウントを選ぶ
   2. 「このアプリは Google で確認されていません」と出たら、左下の **詳細** → **PLATZ 学習報告書（安全ではないページ）に移動**
      （ご自身で作ったプログラムなので問題ありません。Google の審査を受けていないアプリには必ずこの表示が出ます）
   3. 許可する内容の一覧が出たら、**すべて選択** にチェックを入れて **続行**（または **許可**）
5. 承認のあと、もう一度 **学習報告書 → ① 初期設定** をクリック（1回目は承認だけで終わることがあります）。
6. 「初期設定が終わりました」と、講師用フォームのURLが出たらOK。

**できたものを確認**：下のシートのタブが次のようになっています。

| シート | 中身 |
|---|---|
| 生徒マスタ | 見本の生徒3人（S001〜S003） |
| 講師マスタ | 見本の講師2人 |
| 報告書 | 見出しだけ（講師が答えるとここに1行ずつ増える） |
| 設定 | 塾名「個人指導塾PLATZ」など |
| 送信ログ | 見出しだけ |
| フォームの回答 1 | フォームの回答の控え（自動でできる。さわらなくてOK） |

## D. 先生のメールで1件試す（5分）

1. **生徒マスタ** の S001（山田 太郎）の行で、
   - **送信方法** を `メール` にする
   - **メールアドレス** を **先生ご自身のメールアドレス** にする
2. **講師マスタ** の1行目の講師名を、先生のお名前にする（例：`〇〇 先生`）。
3. **学習報告書 → フォームのURLを表示** で出たURLを、スマホかパソコンで開く。
4. 講師名＝先生、生徒名＝S001 山田 太郎、区分＝高校生、で最後まで答えて **送信**。
   （2科目目は「なし（1科目だけ）」のままでOK）
5. スプレッドシートの **報告書** シートに1行増え、ステータスが **確認待ち** になっていることを確認。
   右のほうの **送信本文** に、保護者に届く文面ができています。
6. その行の **承認** にチェック ✓ を入れる。
7. 数秒でステータスが **送信済み** になり、先生のメールに「【学習報告書】山田 太郎さん 〇月〇日（〇）」が届けば完了です。

---

## うまくいかないとき

| こうなった | こうする |
|---|---|
| メニューに「学習報告書」が出ない | スプレッドシートを再読み込み（F5）。それでも出なければ、Apps Script で保存（Ctrl＋S）できているか確認 |
| 「シート『〇〇』がありません」と出る | 「① 初期設定」をもう一度実行 |
| フォームの生徒名・講師名が見本のまま | **学習報告書 → フォームの選択肢（講師・生徒）を更新** |
| ✓を入れても「確認待ち」のまま | 設定シートの「承認したらすぐ送る」が「はい」か確認。または **学習報告書 → 承認済みをまとめて送る** |
| 「送信エラー」になった | 同じ行の **エラー** 列に理由が出ます。その文をそのまま送ってください |
| ほかのエラーが出た | 画面のスクリーンショットか、エラーの文をそのまま送ってください |

## 試し終わったら

- 生徒マスタ・講師マスタの見本の行を、実際の生徒・講師に書き換える（手順2）。
- 報告書シートの試しの行は、行ごと削除してかまいません。
