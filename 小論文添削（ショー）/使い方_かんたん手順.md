# 使い方（かんたん手順）

## 最初の1回だけ
1. このフォルダを Claude Code（またはデスクトップ版 Claude）で開く
2. チャットで「準備して」と言う（ライブラリが入る）

> AI エージェントに展開・保存から任せるときは「AIエージェント用_セットアップ手順.md のとおりにセットアップして」と頼む。

## 添削するとき
1. 答案をチャットに貼る　または　`提出/` フォルダに置く
2. チャットで **「ショー、添削お願い」** と言う
3. 大学名・学部学科・字数・題材を聞かれたら答える
4. 完成した添削シートが `添削結果/` に保存される

> 答案ファイルの最初に「大学：」「学部・学科：」「字数：」「題材：」を書いておくと、質問なしで進む。

## ワークシートを作るとき
チャットで **「ショー、〇〇大学 △△学部のワークシート作って」** と言う
→ `ワークシート/` に保存される

## できあがるもの
| フォルダ | 中身 |
|---|---|
| `添削結果/` | 添削シート（Word・A4） |
| `ワークシート/` | 小論文ワークシート（PowerPoint） |
| `大学情報/` | 調べたアドミッションポリシー |

※ 配布・指導の前に、大学公式サイトで最新情報を確認すること。詳しくは「はじめにお読みください.md」。
