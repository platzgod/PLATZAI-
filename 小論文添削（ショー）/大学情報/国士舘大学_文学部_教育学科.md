# 国士舘大学 文学部 教育学科
調べた日: 2026-10-17

## アドミッションポリシー（要点）
- 大学全体：建学の精神・教育理念に共感し、学問への意欲と、多様性・主体性への姿勢を持つ学生を受け入れる（令和8年度 入学者選抜ガイドブックの要約。検索結果の抜粋より）
- 文学部 教育学科の選抜：「本学の教育の理念等を理解し、本学で学ぶ意欲が高く、学部・学科等の求める学生像との適合性を重視した選抜を行う」（大学の選抜資料の抜粋）
- 教育学科固有の方針本文：確認できず（学科別 AP の PDF が公開されているが、作成環境から開けなかった）

## 小論文の評価観点・試験条件（大学公式の過去問で確認）
- 総合型選抜（AO選抜）Ⅰ〜Ⅳ期とも、全学部共通の問題用紙。課題文（エッセイ・小説・新書・新聞）を読んで論述、600字
- 要約を求める回（R8Ⅰ・Ⅲ、R7Ⅲ・Ⅳ）、経験・見聞を交える指定の回（R8Ⅱ・Ⅳ、R7Ⅰ）が多い
- 過去問 PDF と設問の一覧：過去問/国士舘大学_総合型選抜/一覧.md（R7・R8 の8回分）
