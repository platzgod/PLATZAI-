# 小論文添削（ショー）の使い方

小論文の **添削** と **ワークシート作成** を、チャットで頼めるフォルダです。
先生役の「ショー」が、答案を読んで点数・コメント・書き直し例をまとめた添削シート（Word）を作ります。

## 準備（最初の1回だけ）

1. このフォルダを、**Claude Code** または **Claude デスクトップアプリ（Cowork）** で開く
   - Claude Code の場合: このフォルダに移動して `claude` を起動
2. 次のコマンドで必要なライブラリを入れる（Claude に「準備して」と頼んでも可）
   ```
   pip install -r tools/requirements.txt
   ```

## 添削してもらう

1. 答案を用意する（どちらか）
   - チャットにそのまま貼る
   - `提出/` フォルダにファイルを置く（.txt / .docx / .pdf / 写真・スキャン画像）
2. チャットで **「ショー、添削お願い」** と言う
3. 大学名・学部学科・字数・題材（設問文）が書かれていなければ、ショーが質問するので答える
   - 答案ファイルの冒頭に書いておくと、質問なしで進む（例は `提出/サンプル_食品ロス_答案.txt`）
4. ショーがアドミッションポリシーを Web で調べ、添削シートを作る

### 生成されるもの

| 保存先 | 内容 |
|---|---|
| `添削結果/日付_生徒名_大学_学部.docx` | 添削シート（A4・印刷用） |
| `添削結果/日付_生徒名_大学_学部.json` | 添削の中身のデータ（作り直し用） |
| `大学情報/大学_学部_学科.md` | 調べたアドミッションポリシーと出典（次回から使い回す） |

### 添削シートの中身

総合点（100点）と5観点の点数 → 総評 → 良かったところ → 直すと伸びるところ（答案を引用して具体的に）→
答案の原文（段落ごとの字数つき）→ 表記・表現の直し → 構成の見直し（あなたの構成とおすすめ構成）→
書き直し例（規定字数の9割以上）→ アドミッションポリシーとのつながり → 次回の課題

採点の観点（各20点）: 設問への応答 / 構成・論理 / 根拠・具体性 / 学部・アドミッションポリシーとの適合 / 表現・表記（字数を含む）

## ワークシートを作ってもらう

**「ショー、〇〇大学 △△学部のワークシート作って」**（テーマも言うとそれを使う）
→ `ワークシート/` に東洋大学版と同じ形式の .pptx ができます。
コマンドで作る方法は `tools/README_ワークシート作成.md` を参照。

## 注意

- アドミッションポリシーや試験条件は、配布・指導の前に大学公式サイトの最新版で確認してください（ショーは出典 URL を残します）。
- 書き直し例は「一例」です。生徒が書いていない統計や体験は足さない方針で作っています。
- 字数は空白・改行を除いた文字数で数えます。
