# 小論文ワークシート自動作成

東洋大学 食環境科学部版の「小論文ワークシート」（26枚のスライド）と同じ形式の教材を、
**大学名・テーマを入れるだけで** 作る仕組み。

```
大学名・学部・テーマ
   │  ① ウェブ検索で試験条件・過去問を調べる（research.md）
   │  ② Claude が内容を JSON で書く（content.json）
   │  ③ 模範解答の字数・項目をチェック → ずれていれば自動で直させる
   ▼  ④ render.py がデザインを組む
<大学>_<学部>_小論文ワークシート.pptx
```

## 使い方

### A. コマンド一発（Claude API を使う）

```bash
pip install -r tools/requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...

python3 tools/generate.py --university 東洋大学 --faculty 食環境科学部 \
    --department フードデータサイエンス学科 --admission 総合型選抜 \
    --theme "農業経営体数の推移" --theme "食品ロス"
```

| オプション | 内容 |
|---|---|
| `--university`（必須） | 大学名 |
| `--faculty` / `--department` / `--admission` | 学部・学科・入試方式 |
| `--theme`（複数可） | テーマ。1つ目がお手本、2つ目以降が演習。足りない分は AI が学部の傾向から選ぶ |
| `--count` | テーマ数（既定 4） |
| `--minutes` / `--chars` | 試験時間・字数が分かっていれば指定（例: `--minutes 60 --chars 600-800`） |
| `--past-exam 過去問.txt` | 手元の過去問を渡すと、それを最優先でテーマにする（複数可） |
| `--org` | 教材の発行元（既定: 個人指導塾PLATZ） |
| `--no-research` | ウェブ検索をしない |

出力は `ワークシート/<大学>_<学部>/` に `.pptx`・`content.json`・`research.md`。

### B. Claude Code に頼む（API キー不要）

このリポジトリを Claude Code で開き、「〇〇大学 △△学部、テーマ□□で小論文ワークシートを作って」と頼む。
`.claude/skills/shou-worksheet/` の手順どおりに、調べる → JSON を書く → 字数チェック → スライド化 → 目視確認 まで行う。

### C. 内容を手で直して作り直す

```bash
python3 tools/render.py ワークシート/<…>/content.json ワークシート/<…>/ワークシート.pptx
```

## ファイル

| ファイル | 役割 |
|---|---|
| `generate.py` | 入口。調査 → 内容生成 → チェック → スライド化 |
| `render.py` | 内容 JSON → .pptx。東洋大学版のデザインを再現し、文字量からレイアウトを決める |
| `schema.py` | 内容 JSON の形（Claude の構造化出力にもそのまま使う）と検証・字数カウント |
| `prompts.py` | Claude への指示（事実の扱い・字数の目安など） |
| `examples/toyo_food_datascience.json` | 元の東洋大学版を JSON にしたもの（AI の手本も兼ねる） |
| `examples/sample_nursing.json` | 動作確認用の架空の大学（90分・1000字以内・3テーマ） |
| `../ワークシート/` | 上の2つから作った .pptx（生成物もここに入る） |

## 自動で調整されるところ

- **時間配分**: 試験時間から「読む・構成・書く・見直す」を計算（60分 → 5/10/35/10、90分 → 10/15/50/15）。`exam.time_split` で上書き可
- **字数**: 「600〜800字」「1000字以内」の表記、9割の目標字数、模範解答の字数内訳（空白を除いて数える）
- **テーマ数**: 表紙・流れの文言（「テーマ2〜4は自分で埋める」など）
- **レイアウト**: 段落数（4〜6段落）に合わせてカード・行を並べ、長い文は文字を小さく、模範解答が1枚に入らなければ2枚に分ける
- **資料の種類**: 表（table）・キーワード（chips）・条件（conditions）・課題文（text）・なし（none）

## 注意

- 試験時間・字数・過去問は、確認できなかったものは「想定」「オリジナル予想問題」と明記する方針で生成する。**配布前に必ず最新の学生募集要項と照らし合わせること。**
- 模範解答の統計・事実は AI が書くため、数値と出典は目で確認すること。
