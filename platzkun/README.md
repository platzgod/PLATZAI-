# プラッツ君（デモ版）

生徒が分からない問題の写真をアップロードすると、キャラクターの「プラッツ君」が
ヒントを出しながら、文字と音声で解説してくれる Web アプリです。
問題の写真は画面に大きく表示され、いま話している場所にオレンジの枠がつきます。

## 3つの版

| | お試し版<br>`platzkun-demo.html` | claude.ai 版<br>`artifact/` | 塾のパソコン版<br>（このフォルダ） |
|---|---|---|---|
| 動かし方 | ダブルクリックで開くだけ | リンクを開くだけ | Node.js を入れて起動 |
| 質問に本当に答える | ✕（決まった返事） | ○ | ○（APIキーが必要） |
| 費用 | **無料** | claude.ai プランの範囲内 | Claude API の使用料 |
| 問題の拡大と場所の枠 | ○（例題のみ） | ○ | ○ |
| なめらかな声（VOICEVOX） | ✕ | ✕ | ○ |
| 声だけの会話（会話モード） | ○ | ✕（マイクが使えない） | ○ |

## 無料でためす

### お試し版：`platzkun-demo.html`（インストール不要）

**ダブルクリックして Chrome か Edge で開くだけ** で動きます。Node.js も APIキーもいりません
（数式表示のため、インターネット接続は必要です）。

- 「**例題でためしてみる**」を押すと、例題の写真が大きく表示され、話している場所に枠が出ます
- 「会話モード」にチェックを入れると、声だけでやり取りできます（マイクの許可が必要）
- 自分で選んだ写真は中身を読まず、同じ例題でヒントの流れを見せます

このファイルは塾のパソコン版の画面から自動で作っています。画面を直したら
`npm run build:demo` で作り直してください。

### お試しモード（塾のパソコン版を無料で）

塾のパソコン版は、APIキーがないと自動で**お試しモード**になります（画面のタイトルに「（お試しモード）」）。
お試し版と同じ決まった返事に加えて、VOICEVOX の声も試せます。
手順は下の「はじめての準備」の **1 と 4 だけ**（`.env` は作らなくてOK）。

## claude.ai 版（APIキー不要で本当に答える）

`artifact/platzkun-artifact.html` は claude.ai 上で動く版です（公開先：https://claude.ai/artifact/EWJzJUNiXLw86KayVFMY1N ）。
APIキーは使わず、ページを開いた人の claude.ai アカウントで Claude が答えます（その人のプランの利用枠を使います）。
初めて質問するときに「Claude の利用を許可しますか」と聞かれるので、許可してください。
claude.ai の中ではマイクと外部の音声ソフトが使えないので、質問は文字で、読み上げはブラウザ標準の声です。

## はじめての準備（1回だけ）

1. **Node.js をインストール**
   https://nodejs.org/ja から「LTS」版をダウンロードしてインストールします。
2. **Claude の APIキーを用意**
   https://console.anthropic.com にログイン →「API Keys」→「Create Key」で作成し、
   表示された `sk-ant-...` の文字列をコピーします（あとから見られないので注意）。
3. **.env ファイルを作る**
   `platzkun` フォルダの中の `.env.example` をコピーし、名前を `.env` に変えます。
   メモ帳などで開き、`ANTHROPIC_API_KEY=` の後ろにキーを貼り付け、`DEMO_MODE=false` のまま保存します。
   （`.env` は GitHub には上がらない設定になっています。キーは人に見せないでください）
4. **部品のインストール**
   ターミナル（Windows は「コマンドプロンプト」）で `platzkun` フォルダに移動し、次を実行します。
   ```
   npm install
   ```
5. **（なめらかな声にするとき）VOICEVOX を入れる**
   https://voicevox.hiroshiba.jp/ から VOICEVOX（無料）をダウンロードしてインストールします。
   プラッツ君を使うときに、**先に VOICEVOX を起動しておく**と、その声で読み上げます。
   起動していなければ、ブラウザ標準の声になります。
   声の種類や速さは `.env` の `VOICEVOX_SPEAKER`・`VOICEVOX_SPEED` で変えられます。
   VOICEVOX の声は、キャラクターごとの利用規約でクレジット表記（例：「VOICEVOX:ずんだもん」）が必要です。
   画面の左下に自動で表示しています。塾の外に公開するときは、使う声の規約を確認してください。

## 起動のしかた

- **Windows**：`platzkun` フォルダの `start.bat` をダブルクリック
- **Mac / そのほか**：ターミナルで `platzkun` フォルダに移動して
  ```
  npm start
  ```

「プラッツ君が起動しました！」と出たら、ブラウザ（**Google Chrome か Microsoft Edge**）で
http://localhost:3000 を開きます。終わるときは、黒い画面で `Ctrl + C` を押します。

## 使い方

1. 「📷 問題の写真」を押して、問題の写真やスクリーンショットを選びます。
   （`Ctrl + V` で貼り付け、画面へのドラッグ＆ドロップもできます）
2. 分からないところを入力するか、🎤 を押して話します（もう一度押すと聞き取り終了）。
3. 「送る」（または `Enter`）を押すと、プラッツ君がヒントを出してくれます。
   - 問題の写真が左に大きく表示され、いま話している場所にオレンジの枠がつきます
   - 「枠の所を拡大」で枠の部分を大きく、「この場所を見る」で前の返事の場所をもう一度表示
4. ヒントについて考えたことを返事して、やり取りを続けます（1問につき10回まで）。
5. 別の問題に進むときは「次の問題へ」を押します（会話がリセットされます）。

- **会話モード**：チェックを入れると、プラッツ君が話し終わるたびに自動でマイクが聞き取りを始め、
  話し終わると自動で送ります。ボタンを押さずに、声だけでやり取りできます
- 「🔁 もう一度聞く」：最後の解説をもう一度読み上げ
- 「⏹ 止める」：読み上げを止める
- 「声で読み上げ」のチェックを外すと、文字だけになります

## カスタマイズ

| やりたいこと | 変更する場所 |
|---|---|
| プラッツ君の口調・ルールを変える | `prompt.js` |
| お試しモードの返事を変える | `demo.js` |
| VOICEVOX の声の種類・速さ | `.env` の `VOICEVOX_SPEAKER` / `VOICEVOX_SPEED` |
| ブラウザ標準の声の高さ・速さ・種類 | `public/voice.js` の `VOICE_SETTINGS` |
| 別の音声エンジンにする | `public/voice.js` に `speak()` と `stop()` を持つクラスを作り、`createSpeaker()` で返す |
| 1問あたりの往復数を変える | `server.js` の `MAX_TURNS` |
| 難問向けにじっくり考えさせる / 速く安くする | `.env` の `CLAUDE_EFFORT`（`high` / `low`） |

`prompt.js`・`server.js`・`demo.js`・`.env` を変えたら、サーバーを再起動（`Ctrl + C` → もう一度起動）してください。
`public/` の中を変えたときは、ブラウザを再読み込みするだけで反映されます。

## 料金と安全について

- 料金は Claude API の使用量に応じてかかります。サーバーの黒い画面に、1回ごとの使用トークン数が表示されます。
  同じ問題画像を何度も送るため、キャッシュ機能で2回目以降の料金を抑えています。
- 送る前に写真を自動で縮小しています（約115万画素まで）。
- 安全フィルターで回答が止められた場合は、自動で別モデルに切り替えて答えます（サーバー側のフォールバック機能）。
- VOICEVOX・会話モード・枠の表示には、追加の料金はかかりません。

## うまく動かないとき

| 症状 | 対処 |
|---|---|
| 画面のタイトルに「（お試しモード）」と出る | `.env` の場所（`platzkun` フォルダ直下）・キー・`DEMO_MODE=false` を確認して再起動 |
| 「APIキーが正しくありません」 | キーを貼り直す。前後に空白が入っていないか確認 |
| 🎤・会話モードが使えない | Chrome か Edge を使う。マイクの使用を「許可」にする |
| VOICEVOX の声にならない | VOICEVOX を先に起動してから、プラッツ君を起動し直す（黒い画面に「VOICEVOX が見つかりました」と出ればOK） |
| 枠の位置が少しずれる | 写真をまっすぐ・明るく撮ると正確になります（Claude が場所を推定しているため、多少ずれることがあります） |
| 「サーバーにつながりません」 | 黒い画面（サーバー）が閉じていないか確認し、もう一度起動 |
