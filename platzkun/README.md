# プラッツ君（デモ版）

生徒が分からない問題の写真をアップロードすると、キャラクターの「プラッツ君」が
ヒントを出しながら、文字と音声で解説してくれる Web アプリです。

## しくみ

```
 ブラウザ（塾のパソコン）              小さなサーバー（同じパソコン）         Claude API
 ┌────────────────────┐   質問・画像   ┌──────────────────┐   APIキー付き   ┌────────┐
 │ public/            │ ─────────────▶ │ server.js        │ ─────────────▶ │ Claude │
 │  ・写真アップロード │                │  ・.env のキーを使う│                │        │
 │  ・🎤 音声入力      │ ◀───────────── │  ・10往復の上限    │ ◀───────────── │        │
 │  ・文字 + 数式表示  │   解説（少しずつ）└──────────────────┘    解説          └────────┘
 │  ・音声読み上げ     │
 └────────────────────┘
```

APIキーはサーバーの中だけで使うので、ブラウザ側には出ません。

| ファイル | 役割 |
|---|---|
| `server.js` | Claude API に中継するサーバー（Node.js + Express） |
| `demo.js` | お試しモード（無料）で返す決まった返事 |
| `prompt.js` | プラッツ君の解説ルール（システムプロンプト）。口調やルールはここで変更 |
| `public/index.html` / `style.css` | 画面のレイアウトと見た目 |
| `public/app.js` | 画面の動き（写真の読み込み・送信・会話履歴・ボタン） |
| `public/voice.js` | 読み上げ（声の設定）と音声入力。声の差し替えはここ |
| `public/render.js` | 解説文の表示（Markdown + KaTeX の数式） |
| `public/platz.png` | プラッツ君の画像（差し替えるときは同じ名前で上書き。無いときは仮の絵が出ます） |

使っている技術：Node.js / Express / Claude API（`claude-opus-5-5`、画像対応）/
Web Speech API（音声入力）/ speechSynthesis（読み上げ）/ KaTeX / marked

## claude.ai 版（APIキー不要で本当に答える）

`artifact/platzkun-artifact.html` は claude.ai 上で動く版です（公開先：https://claude.ai/artifact/EWJzJUNiXLw86KayVFMY1N ）。
APIキーは使わず、ページを開いた人の claude.ai アカウントで Claude が答えます（その人のプランの利用枠を使います）。
初めて質問するときに「Claude の利用を許可しますか」と聞かれるので、許可してください。
この画面ではマイクが使えないことがあり、そのときは文字で質問します。

## いちばん簡単なお試し版：`platzkun-demo.html`（インストール不要）

`platzkun-demo.html` を **ダブルクリックして Chrome か Edge で開くだけ** で動きます。
Node.js も APIキーもいりません（数式表示のため、インターネット接続は必要です）。
動き・読み上げ・🎤 音声入力・10往復・「次の問題へ」を、料金なしで試せます。
写真の中身は読まず、例題（二次方程式）でヒントの流れを見せます。

- 返事の内容・声の高さや速さ・往復数は、メモ帳で開いて `<script>` のすぐ下の「設定」を書きかえます
- 画像データはファイルのいちばん下に埋め込んであります

## お試しモード（無料・サーバー版）

APIキーがなくても、**お試しモード**で起動できます。Claude は使わず、用意した返事
（二次方程式の例題で、ヒントを段階的に出す流れ）を返すので、料金はかかりません。
次のことを確かめられます。

- プラッツ君の動き（考え中はふわふわ、話している間はゆらゆら）
- 音声の読み上げ（数式の読み方も含む）と、🎤 の音声入力（話した言葉が返事に入ります）
- 写真のアップロード、数式の表示、10往復の上限、「次の問題へ」でのリセット

※ 写真の中身は読みません。どの写真を送っても同じ例題になります。

**お試しモードで動かす手順**：下の「はじめての準備」の **1 と 4 だけ** 行い、起動します
（`.env` は作らなくてOK）。画面のタイトルに「（お試しモード）」と出ます。

本物の解説に切りかえるときは、準備の 2・3 を行い、`.env` を `DEMO_MODE=false` にして再起動します。
反対に、キーを入れたまま無料で動きだけ試したいときは `DEMO_MODE=true` にします。

## はじめての準備（1回だけ）

1. **Node.js をインストール**
   https://nodejs.org/ja から「LTS」版をダウンロードしてインストールします。
2. **Claude の APIキーを用意**
   https://console.anthropic.com にログイン →「API Keys」→「Create Key」で作成し、
   表示された `sk-ant-...` の文字列をコピーします（あとから見られないので注意）。
3. **.env ファイルを作る**
   `platzkun` フォルダの中の `.env.example` をコピーし、名前を `.env` に変えます。
   メモ帳などで開き、`ANTHROPIC_API_KEY=` の後ろにキーを貼り付けて保存します。
   （`.env` は GitHub には上がらない設定になっています。キーは人に見せないでください）
4. **部品のインストール**
   ターミナル（Windows は「コマンドプロンプト」）で `platzkun` フォルダに移動し、次を実行します。
   ```
   npm install
   ```

## 起動のしかた

- **Windows**：`platzkun` フォルダの `start.bat` をダブルクリック
- **Mac / そのほか**：ターミナルで `platzkun` フォルダに移動して
  ```
  npm start
  ```

「プラッツ君が起動しました！」と出たら、ブラウザ（**Google Chrome か Microsoft Edge**）で
http://localhost:3000 を開きます。終わるときは、黒い画面で `Ctrl + C` を押します。

## 使い方

1. 「📷 問題の写真」を押して、問題の写真やスクリーンショットを選びます。
   （`Ctrl + V` で貼り付け、画面へのドラッグ＆ドロップもできます）
2. 分からないところを入力するか、🎤 を押して話します（もう一度押すと聞き取り終了）。
3. 「送る」（または `Enter`）を押すと、プラッツ君がヒントを出してくれます。
   話している間はプラッツ君がゆれます。
4. ヒントについて考えたことを返事して、やり取りを続けます（1問につき10回まで）。
5. 別の問題に進むときは「次の問題へ」を押します（会話がリセットされます）。

- 「🔁 もう一度聞く」：最後の解説をもう一度読み上げ
- 「⏹ 止める」：読み上げを止める
- 「声で読み上げ」のチェックを外すと、文字だけになります

## カスタマイズ

| やりたいこと | 変更する場所 |
|---|---|
| プラッツ君の口調・ルールを変える | `demo.js` | お試しモード（無料）で返す決まった返事 |
| `prompt.js` |
| 声の高さ・速さ・種類を変える | `public/voice.js` の `VOICE_SETTINGS` |
| 別の音声エンジン（VOICEVOX など）にする | `public/voice.js` に `speak()` と `stop()` を持つクラスを作り、`createSpeaker()` で返す |
| 1問あたりの往復数を変える | `server.js` の `MAX_TURNS` |
| 難問向けにじっくり考えさせる / 速く安くする | `.env` の `CLAUDE_EFFORT`（`high` / `low`） |

`prompt.js`・`server.js`・`.env` を変えたら、サーバーを再起動（`Ctrl + C` → もう一度起動）してください。
`public/` の中を変えたときは、ブラウザを再読み込みするだけで反映されます。

## 料金と安全について

- 料金は Claude API の使用量に応じてかかります。サーバーの黒い画面に、1回ごとの使用トークン数が表示されます。
  同じ問題画像を何度も送るため、キャッシュ機能で2回目以降の料金を抑えています。
- 送る前に写真を自動で縮小しています（長い辺が 1568px まで）。
- 安全フィルターで回答が止められた場合は、自動で別モデルに切り替えて答えます（サーバー側のフォールバック機能）。

## うまく動かないとき

| 症状 | 対処 |
|---|---|
| 起動すると「ANTHROPIC_API_KEY が設定されていません」 | `.env` の名前・場所（`platzkun` フォルダ直下）・中身を確認 |
| 「APIキーが正しくありません」 | キーを貼り直す。前後に空白が入っていないか確認 |
| 🎤 が押せない | Chrome か Edge を使う。マイクの使用を「許可」にする |
| 声が出ない・ロボットっぽい | パソコンの音量を確認。Edge だと自然な日本語の声（Nanami など）が選ばれやすいです |
| 「サーバーにつながりません」 | 黒い画面（サーバー）が閉じていないか確認し、もう一度起動 |
