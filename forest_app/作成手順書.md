# フォレスタ学習チェック 作成手順書（Power Apps を初めて触る人向け）

対応する設計書：`設計書_v0.3.md`
使うもの：PLATZ の Microsoft 365 アカウント（アプリを作る人）、PC のブラウザ（Edge または Chrome）、`csv/` の5つのファイル

> 画面のボタン名は、Microsoft のアップデートで少し変わることがあります。見つからないときは、近い名前のボタンを探してください。
> 数式は**そのままコピーして貼り付け**てください。全角・半角や `"`（ダブルクォート）を打ち直すと動かなくなります。

### この手順書の言葉

| 言葉 | 意味 |
|---|---|
| リスト | SharePoint の表。Excel の1シートのようなもの |
| コントロール | 画面に置く部品（ボタン、ラベル＝文字、ギャラリー＝くり返しの一覧） |
| プロパティ | 部品の設定（Text＝表示する文字、OnSelect＝押したときの動き、Items＝一覧の中身 など） |
| 数式バー | 画面上の `fx` の横の入力欄。ここにプロパティの数式を貼る |
| コレクション | アプリが手元に読み込んだ表（名前が `col` で始まるもの） |
| 変数 | アプリが覚えておく値（名前が `g` で始まるもの） |

## 0. 最初に確認すること（10分）

1. Microsoft 365 管理センター（admin.microsoft.com）→ **ユーザー** → **アクティブなユーザー** → 先生のアカウント → **ライセンスとアプリ**。
2. 「アプリ」の一覧で **Power Apps for Office 365**（または Power Apps for Microsoft 365）にチェックが入っているかを見る。
3. 入っていなければ、ここで止めて赤神に連絡する（設計書10章。費用が出るかの確認が先です）。

## 1. SharePoint にリストを作る

### 1-1. サイトを決める

1. ブラウザで PLATZ の SharePoint（`https://（会社名）.sharepoint.com`）を開く。
2. 先生だけがメンバーのサイトを使う。なければ **＋サイトの作成** → **チームサイト** → 名前「学習チェック」→ メンバーに先生を追加。

### 1-2. リストを6つ作る

サイトのトップ → **＋新規** → **リスト** → **空白のリスト** → 名前を入れて **作成**。次の6つを、**名前を英字のまま**作ります。

| リスト名 | 説明（説明欄に入れる） |
|---|---|
| Students | 生徒 |
| Units | 単元（フォレスタの目次） |
| Terms | 学期 |
| Roadmap | ロードマップ（予定） |
| CheckLog | チェック記録（実績） |
| Settings | 設定 |

### 1-3. 列を追加する

リストを開く → 一番右の列見出しの **＋列の追加** → 型を選ぶ → **次へ** → 名前を入れて **保存**。
**表の上から順に**追加してください（あとで貼り付けるときの列の順になります）。「タイトル」列は最初からあるので追加しません。

| リスト | 追加する列（名前：型） |
|---|---|
| Students | Grade：1行テキスト → Campus：1行テキスト → Pattern：1行テキスト → Status：1行テキスト |
| Units | Grade：1行テキスト → Subject：1行テキスト → UnitName：1行テキスト → SortOrder：数値 |
| Terms | TermName：1行テキスト → StartDate：1行テキスト → EndDate：1行テキスト |
| Roadmap | TermCode：1行テキスト → Pattern：1行テキスト → Grade：1行テキスト → Subject：1行テキスト → UnitCode：1行テキスト → PlanWeek：1行テキスト → TargetLaps：数値 |
| CheckLog | CheckDate：1行テキスト → StudentID：1行テキスト → Subject：1行テキスト → UnitCode：1行テキスト → UnitGrade：1行テキスト → Kind：1行テキスト → TeacherEmail：1行テキスト → TeacherName：1行テキスト |
| Settings | SettingValue：1行テキスト → Description：複数行テキスト |

- 日付も**1行テキスト**にします（設計書 4-0。日付が1日ずれるのを防ぐため）。

### 1-4. 「一意」とインデックスを設定する（重複防止と、記録が増えたときのため）

1. **CheckLog** を開く → 右上の歯車 → **リストの設定**。
2. 「列」の一覧の **タイトル** をクリック → **一意の値を適用する** を **はい** → **OK**（インデックスを作るか聞かれたら **OK**）。
3. リストの設定に戻り → **インデックス付きの列** → **新しいインデックスの作成** → **StudentID** → 作成。同じように **Subject**、**UnitGrade** も作る。
4. **Students・Units・Terms** も、2 と同じ手順でタイトルを「一意」にする。
5. **Roadmap** は、3 と同じ手順で **TermCode** のインデックスを作る。

## 2. サンプルの表を貼り付ける

`csv/` のファイルを Excel で開いて、リストに貼り付けます（**中身は架空のサンプル**です。本物はフォレスタの目次が届いてから入れます）。

| ファイル | 貼り付け先 | 行数 |
|---|---|---|
| 生徒.csv | Students | 20 |
| 単元.csv | Units | 180 |
| 学期.csv | Terms | 5 |
| ロードマップ.csv | Roadmap | 420 |
| 設定.csv | Settings | 3 |
| （なし） | CheckLog | 0（アプリが書き込む） |

1. CSV を Excel で開く → **2行目から最後の行まで**（見出しの行は除く）、**全部の列**を選んでコピー。
2. リストを開く → 上の **グリッド ビューで編集** → 一番下の新しい行の、**タイトル**のマスをクリック → 貼り付け（Ctrl＋V）。
3. 保存されるまで待ち、**グリッド ビューを終了**。
4. うまく貼れないときは **100行ずつ**に分けて貼る。

**確かめること**：Roadmap の PlanWeek が `2026-10-12` のように表示されていること。Excel が日付に変えて `2026/10/12` になっていたら、Excel の列を「文字列」にしてから CSV を開き直す（または「データ」→「テキストまたは CSV から」で、その列を「テキスト」にして読み込む）。

## 3. アプリを作る

1. **make.powerapps.com** を開き、PLATZ のアカウントでサインイン。
2. 左の **＋作成** → **空のアプリ** → **空のキャンバスアプリ**（作成）→ 名前「フォレスタ学習チェック」、形式 **タブレット** → **作成**。
3. 上のメニューの **設定**（歯車）：
   - **表示** → 画面の向き：**縦**
   - **全般** → **データ行の制限**：`2000`（設計書8章）
4. 左の **データ**（円柱の形）→ **データの追加** → **SharePoint** → 1-1 のサイト → 6つのリスト全部にチェック → **接続**。

### 3-1. App（アプリ全体）

左の **ツリー ビュー** → 一番上の **App** を選ぶ → 数式バーの左のプロパティ一覧で **OnStart** を選んで貼る。

**App.OnStart**
```
Set(gMe, User());
Set(gTerm, Blank());
Set(gGrade, "全員");
Set(gCampus, "全校舎");
Set(gMode, "check");
Set(gBusy, false)
```

ツリー ビューの App の「…」→ **OnStart を実行**。

## 4. ホーム画面（scrHome）

最初からある **Screen1** の名前を `scrHome` に変える（ツリー ビューで名前をダブルクリック）。

**scrHome.OnVisible**（ホームに戻るたびに、設定・生徒・単元・学期を読み直す）
```
ClearCollect(colSettings, Settings);
Set(gDefaultTarget, Coalesce(Value(LookUp(colSettings, Title = "DefaultTargetLaps").SettingValue), 2));
Set(gLapMode, Coalesce(LookUp(colSettings, Title = "LapCountMode").SettingValue, "合算"));
Set(gGraceDays, Coalesce(Value(LookUp(colSettings, Title = "DelayGraceDays").SettingValue), 0));
ClearCollect(colTerms, Terms);
ClearCollect(colUnitsAll, Units);
ClearCollect(colStudents,
    AddColumns(Filter(Students, Status = "在籍"),
        GradeB, If(Pattern = "先取り", Switch(Grade, "中1", "中2", "中2", "中3", Grade), Grade)));
If(IsBlank(gTerm),
    Set(gTerm, LookUp(colTerms, DateValue(StartDate) <= Today() && DateValue(EndDate) >= Today()));
    If(IsBlank(gTerm), Set(gTerm, First(Sort(Filter(colTerms, DateValue(StartDate) > Today()), StartDate))));
    If(IsBlank(gTerm), Set(gTerm, First(Sort(colTerms, StartDate, SortOrder.Descending))))
)
```
- `GradeB` は「その生徒が使う2つ目の学年」です。先取りの生徒は1つ上の学年、標準の生徒は自分の学年と同じになります。
- 学期は、今日を含む学期 → なければ次の学期 → なければ最後の学期、の順に選びます。

置くもの（**＋挿入** から）：

| 名前 | 種類 | プロパティ |
|---|---|---|
| lblTitle | テキスト ラベル | Text：`"フォレスタ学習チェック"`、Size：28 |
| lblTeacher | テキスト ラベル | Text：`"先生：" & gMe.FullName` |
| drpTerm | ドロップダウン（クラシック） | Items：`Sort(colTerms, StartDate)`、Value：`TermName`、Default：`gTerm.TermName`、OnChange：`Set(gTerm, drpTerm.Selected)` |

| btnBoard | ボタン | Text：`"先生ボード"`、Height：120、OnSelect：`Navigate(scrBoard)` |

## 7. 単元チェック画面（scrCheck）

**＋新しい画面** → **空** → 名前 `scrCheck`。

| 名前 | 種類 | プロパティ |
|---|---|---|
| btnBack3 | ボタン | Text：`"← 教科を選び直す"`、OnSelect：`Back()` |
| lblHead3 | テキスト ラベル | Text：`gStudent.Title & "　" & gSubject & "　（" & gTerm.TermName & "）"`、Size：26 |

**galUnits.Items**（並び順：今週の予定 → 遅れ → 今学期のほかの予定 → 済 → 予定外）
```
With(
    {
        wk: Text(DateAdd(Today(), 1 - Weekday(Today(), StartOfWeek.Monday)), "yyyy-mm-dd"),
        tKey: Text(Today(), "yyyy-mm-dd")
    },
    Sort(
        AddColumns(
            AddColumns(
                AddColumns(
                    AddColumns(colUnits As u,
                        PlanWeek, LookUp(colPlan As p, p.UnitCode = u.Title).PlanWeek,
                        Target, Coalesce(LookUp(colPlan As p, p.UnitCode = u.Title).TargetLaps, gDefaultTarget),
                        LessonLaps, CountRows(Filter(colLog As l, l.UnitCode = u.Title && l.Kind = "授業")),
                        HomeLaps, CountRows(Filter(colLog As l, l.UnitCode = u.Title && l.Kind = "宿題")),
                        LessonToday, !IsBlank(LookUp(colLog As l, l.Title = gStudent.Title & "|" & u.Title & "|授業|" & tKey)),
                        HomeToday, !IsBlank(LookUp(colLog As l, l.Title = gStudent.Title & "|" & u.Title & "|宿題|" & tKey))
                    ),
                    Laps, If(gLapMode = "合算", LessonLaps + HomeLaps, LessonLaps),
                    IsThisWeek, PlanWeek = wk
                ),
                Status, If(
                    Laps >= Target, "済",
                    IsBlank(PlanWeek), If(Laps > 0, "途中", "予定外"),
                    Laps = 0 && DateAdd(DateValue(PlanWeek), 6 + gGraceDays) < Today(), "遅れ",
                    Laps > 0, "途中",
                    "予定前")
            ),
            SortKey, If(
                IsThisWeek && Status <> "済", 0,
                Status = "遅れ", 1,
                !IsBlank(PlanWeek) && Status <> "済", 2,
                Status = "済", 3,
                4) * 10000 + SortOrder
        ),
        SortKey
    )
)
```

**状態の色**（rectStatus.Fill と lblStatus.Color）

**btnLesson.OnSelect**（押したらその場で1件保存。同じ日・同じ種類が登録済みなら保存しない）
```
If(!gBusy,
    Set(gBusy, true);
    With({k: gStudent.Title & "|" & ThisItem.Title & "|授業|" & Text(Today(), "yyyy-mm-dd")},
        IfError(
            Collect(colLog, Patch(CheckLog, Defaults(CheckLog), {
                Title: k,
                CheckDate: Text(Today(), "yyyy-mm-dd"),
                StudentID: gStudent.Title,
                Subject: gSubject,
                UnitCode: ThisItem.Title,
                UnitGrade: ThisItem.Grade,
                Kind: "授業",
                TeacherEmail: gMe.Email,
                TeacherName: gMe.FullName
            })),
            ClearCollect(colLog, Filter(CheckLog, StudentID = gStudent.Title && Subject = gSubject));
            Notify("保存できなかったか、すでに登録済みです。表示を最新にしました。", NotificationType.Warning),
            Notify(ThisItem.Title & " 授業✓を保存しました", NotificationType.Success)
        )
    );
    Set(gBusy, false)
)
```

**btnUndoLesson.OnSelect**（今日付けた授業✓を1件消す）
```
With({k: gStudent.Title & "|" & ThisItem.Title & "|授業|" & Text(Today(), "yyyy-mm-dd")},
    IfError(
        Remove(CheckLog, LookUp(CheckLog, Title = k)),
        Notify("取り消せませんでした。ホームに戻ってから、もう一度開いてください。", NotificationType.Error),
        RemoveIf(colLog, Title = k);
        Notify("今日の授業✓を取り消しました", NotificationType.Information)
    )
)
```

- 宿題のボタンは、数式の中の `"|授業|"` と `Kind: "授業"`（取消は `"|授業|"` と表示の文）を `宿題` に変えるだけです。

```
                ),
                Laps, If(gLapMode = "合算", LessonLaps + HomeLaps, LessonLaps),
                IsThisWeek, PlanWeek = wk
            ),
            Status, If(
                Laps >= Target, "済",
                Laps = 0 && DateAdd(DateValue(PlanWeek), 6 + gGraceDays) < Today(), "遅れ",
                Laps > 0, "途中",
                "予定前")
        ),
        PlanWeek & Subject & UnitCode
    )
)
```

## 12. 運用で中身を変えるとき（アプリは直さない）

| 変えたいこと | どこを直すか |
|---|---|
| フォレスタの本物の単元を入れる | Units のサンプル行を全部消して、目次の表を貼る（単元コードの付け方は設計書 4-2） |
| ロードマップを作り直す | Roadmap の行を直す・足す（PlanWeek は月曜日の日付） |
| 新しい年度の学期を入れる | Terms に行を足す（Title は `2027-1` のように） |
| 4月の進級 | Students の Grade を書き換える。パターンもここで変えられる |
| 目標周回・数え方・猶予日数 | Settings の SettingValue を直す |
| 退塾・休塾 | Students の Status を「退塾」「休塾」にする（記録は残る） |

- 変えたら、アプリのホームに戻れば反映されます。
