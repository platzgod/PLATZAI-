# PLATZAI-

## 小論文添削キット（`小論文添削/`）

Claude Code で高校生の小論文・志願理由書（PDF / 画像 / Word）を添削し、総合評価（A〜E）と「原文（下線）／番号ごとの直し方／修正後の文章」の 3 列を並べた A3 横の Word で納品するためのセットです。

```
小論文添削/
├── CLAUDE.md            … 添削の指示書（Claude Code が自動で読み込む）
├── 添削実行.bat          … タスクスケジューラー用の自動実行ファイル
├── 添削前/               … 生徒の提出物を入れる（1 人 1 フォルダ、または 1 ファイル）
├── 添削後/               … 「<提出物名>_添削完了.docx」が出力される
└── tools/
    ├── pending.py        … 未処理ファイルの一覧と本文抽出
    ├── make_docx.py      … 添削結果 JSON から Word を生成
    └── sample_result.json… JSON の記入例
```

### セットアップ（Windows）
1. `小論文添削` フォルダごと OneDrive（例: `C:\Users\<ユーザー名>\OneDrive\小論文添削`）にコピーする。
   フォルダの場所は CLAUDE.md からの相対パスで決まるので、パスの書き換えは不要です。
2. `pip install python-docx pdfplumber`
3. 提出物を `添削前` に入れる。
   - 手書きなど複数枚のとき: `添削前/小論文_田中太郎_早稲田大学_法学部/` フォルダを作り、`設問.jpg`（設問・字数を含む）と本文 `1.jpg`, `2.jpg` … を入れる。
   - 1 ファイルのとき: `添削前/志願理由書_田中太郎_早稲田大学_法学部.docx`（設問も同じファイルに入れる）。
   - 先頭の種類は「小論文」か「志願理由書」。

### 使い方
- **手動:** `小論文添削` フォルダで Claude Code を起動し、「小論文添削フォルダを処理して」と言う。
- **自動:** タスクスケジューラーで `添削実行.bat` を好きな時刻に実行するよう登録する。実行ログは `添削後\実行ログ.txt` に残ります。
  パソコンが起動していて OneDrive が同期済みであることが前提です。最初は手動で一度動かして確認してください。

### 仕組み
添削の中身（指摘・理由・型・完成文・段落の入れ替え・提出前の確認・アドミッションポリシー）は Claude が JSON にまとめ、書式は `make_docx.py` が担当します。
指摘箇所は原文中の文字列で指定し、丸数字は本文の出現順に自動で振られます（①〜⑳、21 以降は (21)(22)…）。
各指摘に付けた id を `[[id]]` と書くと、直し方や修正後の文章の中でその丸数字に置き換わります。

生徒の提出物と添削結果は `.gitignore` によりリポジトリには含まれません。
