# PLATZAI-

## 小論文添削キット（`小論文添削/`）

Claude Code で高校生の小論文・志願理由書（PDF / 画像 / Word）を添削し、総合評価（A〜E）と「原文（下線）／番号ごとの直し方／修正後の文章」の 3 列を並べた A3 横の Word で納品するためのセットです。

```
小論文添削/                 … OneDrive\00AIGod\AI自動添削システム に置く
├── 提出のしかた.txt     … 先生向けの提出ルール
├── セットアップ.bat     … 初回だけ実行（確認・インストール・タスク登録）
├── 添削実行.bat         … 今すぐ手動で添削するとき
├── CLAUDE.md            … 添削の指示書（Claude Code が自動で読み込む）
├── 添削前/              … 先生が提出物を入れる（1 人 1 フォルダ）
├── 添削後/              … 添削完了.docx と 納品一覧.txt が返る
├── ログ/                … 実行の記録（30 日で自動削除）
├── 作業用/              … Claude の作業ファイル
└── tools/
    ├── run.ps1          … 自動実行の本体（未処理が無ければすぐ終了）
    ├── setup.ps1        … セットアップの本体
    ├── pending.py       … 未処理の一覧と本文抽出（同期中・保留の判定）
    ├── make_docx.py     … 添削結果 JSON から Word を生成
    ├── note.py          … 納品一覧.txt への記録
    └── sample_result.json … JSON の記入例
```

### 全体の流れ
```
先生 → OneDrive「添削前」に入れる
          ↓（OneDrive が自宅のデスクトップ PC に同期）
デスクトップ PC のタスクスケジューラー（毎日 13:00・21:00。PC が切れていたら次の起動時）
          ↓ run.ps1 … 未処理があるか確認（入れて 10 分以内は同期待ちで次回へ）
Claude Code … 読み取り → 添削 → Word 生成
          ↓
OneDrive「添削後」に 添削完了.docx と 納品一覧.txt → 先生が受け取る
```

### セットアップ（デスクトップ PC で 1 回だけ）
1. 次をインストールする。
   - Claude Code（インストール後、一度 `claude` を起動してログインしておく）
   - Git for Windows
   - Python（インストール時に「Add python.exe to PATH」にチェック）
2. このフォルダ `小論文添削` の中身を `OneDrive\00AIGod\AI自動添削システム` にコピーする。
3. `セットアップ.bat` をダブルクリックする。NG が出たら直して再実行する。
4. 先生に `AI自動添削システム` フォルダを OneDrive で共有する（編集可）。`提出のしかた.txt` を案内する。
5. 試しに 1 件入れ、10 分待ってから `添削実行.bat` をダブルクリックし、`添削後` に Word が出るか確認する。

時刻を変えるときは PowerShell で `tools\setup.ps1 -Times 12:30,20:00` のように実行し直す。

### 仕組み
添削の中身（指摘・理由・型・完成文・段落の入れ替え・提出前の確認・アドミッションポリシー）は Claude が JSON にまとめ、書式は `make_docx.py` が担当します。
指摘箇所は原文中の文字列で指定し、丸数字は本文の出現順に自動で振られます（①〜⑳、21 以降は (21)(22)…）。
各指摘に付けた id を `[[id]]` と書くと、直し方や修正後の文章の中でその丸数字に置き換わります。

生徒の提出物と添削結果は `.gitignore` によりリポジトリには含まれません。
